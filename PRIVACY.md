# Privacy policy

Effective 1 September 2026.

Hinge Profile Optimizer is a skills-only plugin. It has no server, user accounts, analytics, advertising, telemetry, or external data store. The plugin does not independently collect, retain, sell, or transmit personal information.

Text, screenshots, photos, and files supplied to Claude Code, Codex, ChatGPT, or another compatible host are processed by that host under its privacy policy and account settings. Hinge Profile Optimizer only supplies instructions that tell the host model how to review and improve a dating profile.

Dating profiles can contain sensitive personal information. Users should crop or blur surnames, workplaces, social handles, exact locations, children, and unrelated third-party faces unless those details are necessary for the requested review.

If a future version adds network services or independent data collection, this policy will be updated before that version is published.

For privacy questions, open an issue at <https://github.com/b1rdmania/hinge-profile-optimizer/issues>.
