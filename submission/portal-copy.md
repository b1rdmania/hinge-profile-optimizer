## Release notes

Initial public submission of a skills-only Hinge profile plugin for ChatGPT and Codex. It provides an eight-phase profile workflow backed by 29 cited studies, platform data, signaling theory, and clearly labelled practical guidance. It contains no MCP server, authentication, telemetry, or external data store.

## Data and permissions

The plugin contains one skill and its research references. It uses the host product's existing conversation, image, and file capabilities. It does not connect to Hinge, access a dating account, create an account, authenticate a user, collect analytics, or retain data independently.

Users may supply profile screenshots, photos, prompts, settings, and personal background. The skill asks users to crop or blur unnecessary identifiers and unrelated third-party faces. It evaluates profile communication and image quality without attractiveness scoring, identity recognition, or sensitive-trait inference.
